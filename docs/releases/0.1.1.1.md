# Release 0.1.1.1

## Changes

- **Discover `PageSize`**: `DiscoverOptions.PageSize` sets `bookmall/cell/change` `limit` (default 20, max 50).
- Discover feed cursors (`d1.…`) now include optional `limit` for consistent pagination.
- CLI: `ohg discover --page-size N` (reuses existing global `--page-size` flag).

## Publish (AmatsuZero/openhongguo)

1. Merge to `main`, run CI + contract.
2. `git tag v0.1.1.1 && git push origin v0.1.1.1`
3. `git tag xcf-v0.1.1.1 && git push origin xcf-v0.1.1.1` (or workflow_dispatch) — rebuilds xcframework and updates root `Package.swift` checksum.
4. CrawlerBot: bump `hongguo/swift/Package.swift` to `from: "0.1.1.1"` and pin new sha256 from release.
