## Summary

- Add `DiscoverOptions.PageSize` (default 20, max 50) for discover feed `cell/change` requests, aligned with existing `SearchOptions.PageSize`.
- Feed cursors (`d1.…`) optionally carry `limit` so pagination stays consistent; cursors without `limit` decode as 20.
- CLI: `ohg discover` respects global `--page-size`.

## Motivation

Discover first pages often return fewer cards than search; configurable limit lets clients request larger pages without multiple round-trips.

## Test plan

- [ ] `make test-go`
- [ ] `ohg discover --page-size 30 --json` (items length vs default)
- [ ] Pagination with cursor from first page still works

## Backward compatibility

Existing discover cursors remain valid; missing `limit` in JSON → 20.
